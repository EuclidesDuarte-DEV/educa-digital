# Educa+ Digital V111.43 — Guia visual no botão Começar meu treino

Base: V111.42 (inicialização única da LIA, arquitetura organizada).

## Mudança
O guia de primeira visita agora mostra três destaques, na ordem:
1. **Começar meu treino** — CTA da página inicial, com chamada para iniciar a experiência.
2. **Banco** — primeiro treino e pré-teste de Pix no celular simulado.
3. **Acessibilidade** — botão no cabeçalho, sem abrir o painel automaticamente.

O usuário pode avançar, pular, fechar ou tocar diretamente no alvo para ativá-lo. O guia pode ser reaberto pelo **Como usar**. A versão da preferência de conclusão foi atualizada para que usuários que viram o guia antigo recebam a nova explicação uma vez.

## Uso local
Na pasta extraída, execute `npm.cmd install` (uma vez) e `npm.cmd run dev`. Acesse o endereço anunciado pelo terminal, normalmente http://localhost:8787.

Esta versão **não** foi publicada no Cloudflare nem no GitHub. Recursos locais da LIA continuam sujeitos à configuração do computador; a inicialização única continua disponível em `INICIAR_EDUCA_COM_LIA.cmd`.
