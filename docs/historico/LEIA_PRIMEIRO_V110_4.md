# Educa+ Digital V110.4 — Voz neural / visemas com precisão temporal

Projeto preserva recursos da V110.3, pré-teste, IA, WhatsApp original, modo livre, 22 atividades e base local D1.

**Comandos no Windows:**
```powershell
npm.cmd install
npm.cmd test
npm.cmd run dev
```

**Configuração adicional opcional:** leia `CONFIGURAR_VOZ_NEURAL_V110_4.md`. Sem Azure, a plataforma não inventa sincronismo fonêmico: mantém a animação aproximada existente.

Não publique sem conferir os testes e habilitar limites de consumo/segurança se usar Azure.
