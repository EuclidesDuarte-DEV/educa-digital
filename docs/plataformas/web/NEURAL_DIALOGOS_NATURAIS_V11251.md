# Naturalidade de diálogos — V112.51

As falas dos personagens deixam de repetir “fictício”, “treino” e “simulação” a cada mensagem. O cabeçalho permanente mantém o aviso de contato fictício e o aplicativo de Pix permanece um treino sem movimentação financeira.

Perguntas ambíguas passam por uma classificação semântica com histórico restrito a dados não confiáveis. O resultado é uma intenção dentre quatro categorias; o servidor seleciona somente frases revisadas do catálogo seguro, nunca texto livre do modelo. Perguntas claras têm resposta direta. O tempo máximo da classificação é limitado, com fallback.

A história não inventa dados bancários, nomes de terceiros, documentos ou novas alegações de urgência. O usuário pode verificar, recusar e encerrar sem pressão.
